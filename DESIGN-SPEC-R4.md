## Design tokens
- Colors: `--bg:#060a13; --bg2:#0a1120; --card:#0e1729; --card2:#122036; --line:#22345a; --line-soft:#1a2947; --ink:#eef4ff; --ink-soft:#c3d2ea; --ink-mute:#a9bedd; --cyan:#2fd8f2; --cyan-deep:#0e7d99; --amber:#ffb02e; --amber-ink:#1a1200; --green:#3ddc84; --focus:#2fd8f2`
- Fonts: Unbounded (headings, weight 500/700/900, uppercase hero), Manrope (body, 400-800), JetBrains Mono (labels/meta, uppercase mono tags). Load via `next/font/google` (Unbounded, Manrope, JetBrains_Mono) — do NOT use Google Fonts CDN link.
- Base: dark only (`color-scheme: dark`), body 17px/1.6 Manrope, max-width 1220px `.wrap` (padding 21px mobile / 34px ≥760px), sections `padding:64px 0 6px`, `[id]{scroll-margin-top:96px}`, `::selection` cyan on dark, focus-visible 3px cyan outline.
- Ambient background: fixed `.bg-fx` — two soft radial fields (cyan top-right, amber mid-left) + 56px grid, masked to fade at top. `overflow-x:hidden` on body.
- Buttons: `.btn` min-height 52px, radius 14px, weight 800; `.btn-amber` amber bg → hover cyan; `.btn-hire` 60px tall, 18px, amber glow shadow; `.btn-ghost` card bg, hover cyan border. Cards: `background:var(--card); border:1.5px solid var(--line-soft); border-radius:20-22px; hover → border-color:var(--cyan-deep)`.
- Section head pattern: `.sec-tag` (mono, 13px, letter-spacing .12em, cyan, uppercase, e.g. "01 · Selected work") + `h2` Unbounded 700, clamp(27px,4.6vw,42px) + `p` ink-soft 17.5px, max 64ch.
- Reveal on scroll: `.rv` opacity 0 → translateY(16px) → `.in` visible, 0.55s ease; IntersectionObserver threshold 0.08; respect `prefers-reduced-motion` (no animation).
- Counters: `[data-count]` animate 0→target in 900ms on view (skip if reduced motion).
