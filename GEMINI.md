# Workspace Rules & Guidelines

## Git Commit Guidelines
- Whenever making git commits and pushes, ALWAYS use meaningful, concise, and relevant commit messages that accurately reflect the actual modifications (e.g. using Conventional Commits: `feat: ...`, `fix: ...`, `refactor: ...`, `style: ...`, `docs: ...`).
- Never use generic or hardcoded commit messages (like `feat: Create initial React project`) unless genuinely creating an initial project.
